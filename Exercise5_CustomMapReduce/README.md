# Exercise 5 - Custom MapReduce with Hadoop Streaming

## Objective
Analyze 50,000 sales records using Hadoop Streaming and Python MapReduce.

## Dataset Format
Date, Product, Price, City, Customer, Quantity

## Analysis Completed
1. City-wise Sales Analysis
2. Monthly Sales Analysis
3. Product Quantity Analysis
4. Sales Visualization

## Key Results
- Highest sales city: Ahmedabad
- Highest sales month: August 2024
- Most sold product: Laptop
