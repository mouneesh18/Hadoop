# Exercise 4 - Hadoop Word Count

## Objective
Implement the Hadoop WordCount MapReduce program to count the frequency of words from multiple text files.

## Files
- file1.txt
- file2.txt
- file3.txt

## Input
Three text files were uploaded to HDFS and processed using the Hadoop WordCount MapReduce program.

## Output
The Hadoop WordCount program generated the frequency count of each word from the input files.

## Result
Successfully implemented the Hadoop WordCount MapReduce program and obtained the word frequency count.
